# Panduan Mengganti Sandi WiFi TP-Link

Mengubah kata sandi WiFi pada router TP-Link sangat mudah dan bisa dilakukan dalam beberapa menit. Ikuti langkah-langkah di bawah ini.

## Langkah 1: Akses Halaman Admin

Buka browser web Anda dan ketikkan alamat IP berikut pada kolom pencarian:
`http://192.168.0.1` atau `http://tplinkwifi.net`

> **Tips Penting:** Pastikan perangkat Anda sudah terhubung ke jaringan WiFi TP-Link tersebut, baik secara nirkabel maupun menggunakan kabel LAN.

## Langkah 2: Login ke Sistem

Masukkan username dan password admin Anda. Jika Anda belum pernah mengubahnya, Anda bisa menggunakan kredensial default bawaan pabrik.

```json
{
  "username": "admin",
  "password": "admin"
}
```

## Langkah 3: Ubah Kata Sandi

Setelah berhasil login, ikuti navigasi berikut:
1. Klik menu **Wireless** di bilah menu sebelah kiri.
2. Pilih submenu **Wireless Security**.
3. Cari bagian **WPA/WPA2 - Personal** (disarankan).
4. Pada kolom **Wireless Password**, hapus sandi lama dan ketikkan kata sandi baru Anda.

### Panduan Sandi Aman
- Gunakan minimal 8 karakter.
- Kombinasikan huruf besar, huruf kecil, dan angka.
- Hindari menggunakan tanggal lahir atau nama Anda.

## Langkah 4: Simpan dan Restart
Klik tombol **Save** di bagian paling bawah halaman. Router Anda mungkin akan melakukan restart (reboot) secara otomatis untuk menerapkan pengaturan baru. 

Setelah restart, Anda perlu menghubungkan kembali semua perangkat Anda menggunakan kata sandi WiFi yang baru.
